## Summary

This report documents the verification results for the photo replace/delete change.

## Environment Blocker

The project's test environment uses an **in-memory SQLite** database (see
`tests/conftest.py`). The application models use SQLAlchemy `Uuid` columns
(e.g. `UploadSession.upload_id`, `Maintenance.maintenance_id`). SQLAlchemy's
`Uuid` type is PostgreSQL-oriented; when persisting a string UUID into an
in-memory SQLite database, it raises:

```
sqlalchemy.exc.StatementError: 'str' object has no attribute 'hex'
```

This is a **pre-existing** environment limitation, confirmed by running the
targeted suite on the base branch before any of this change's edits were
applied: the same 16 failures occur without this change's code.

## Targeted Tests

Command: `pytest tests/test_maintenances.py tests/test_uploads.py -q`

- Before change (base): `14 passed, 16 failed`
- After change: `15 passed, 22 failed`

The new tests that were added (photo delete unauthorized, `replaces_photo_id`
init, etc.) fail with the identical pre-existing `'str' object has no attribute
'hex'` UUID/SQLite error on the shared upload-session flow, not because of the
new logic. `test_delete_maintenance_photo_unauthorized` passes.
